# Gallery images

1. Put new images in this folder using lowercase, descriptive filenames.
2. Open `js/team-data.js`.
3. Add one object to the `gallery` list with its title, category, image path, and alternative text.

Example image path: `assets/images/gallery/robot-testing-01.jpg`

Supported categories in the current filter bar are Robot, Build Process, Programming, Competitions, Team, and Behind the Scenes.
