# Member photos

Put member profile images in this folder. Use short lowercase filenames, for example:

- `shresht-hiremath.jpg`
- `arnav-kotaru.jpg`

Then set the corresponding `photo` value in `js/team-data.js` to a path such as `assets/images/members/shresht-hiremath.jpg`.

Square or 4:5 portrait images work best. The site crops images with `object-fit: cover`.
